session entry template
======================

This stays in a .txt file because the submission checker treats Markdown
headings as entries. Each entry needs a time line, at least 100 characters of
text and an image. Bold labels keep the sections from being read as extra entries.

Include the details that help someone check the work: part numbers, datasheet
pages, measurements, what you tried instead, and exact errors when something
failed.
