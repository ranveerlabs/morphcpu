# case/

Enclosure for the MorphCPU board.

| File | Purpose |
|---|---|
| _(tbd)_ `morphcpu-case.FCStd` / `.step` | Parametric CAD source |
| _(tbd)_ `morphcpu-case-top.stl` | Exported top shell, print-ready |
| _(tbd)_ `morphcpu-case-bottom.stl` | Exported base, print-ready |

Both the CAD source **and** the exported STLs are tracked — the STLs are the deliverable.

Constraints to honour: USB-C connector cutout, reset button access, and a window or light
pipe array over the 16 status LEDs so grid activity stays visible with the case closed.
